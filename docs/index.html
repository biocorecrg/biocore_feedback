Biocore Feedback

Universal Slack feedback microservice and embeddable Web Component for Biocore CRG web apps.

📍 Where is it hosted and where does the .env go?

Because Slack incoming webhooks are sensitive secrets (and Slack blocks direct browser requests due to CORS), the setup consists of two parts:

1. Central Service (biocore_feedback)

Hosted on your VM / Docker / internal server (e.g. https://feedback.crg.es)

  • Holds the .env file: with SLACK_WEBHOOK_URL="https://hooks.slack.com/...".
  • Receives the feedback data from all your apps and sends it to Slack.
  • Applies rate-limiting so users can't flood the Slack channel.
2. Client Apps (e.g. genomics_apps)

Any CRG web app (Django, Shiny, Vue, Streamlit, etc.)

  • Does NOT need any Slack secret: No webhook URL in the app's .env!
  • Simply includes 2 lines of HTML: the script and the <biocore-feedback> badge.
  • The browser connects to biocore_feedback automatically.

🚀 How to embed in any app

Add these two lines before the closing </body> tag in your app's template (e.g. base.html in Django or your HTML page):

<!-- Load the widget script from your central biocore_feedback server --> <script src="https://feedback.crg.es/widget.js" defer></script> <biocore-feedback app-name="Genomics Apps"></biocore-feedback>
Widget Configuration Attributes:
Attribute Default Description
app-name document.title The name of your application shown in the form and sent to Slack.
api-url Origin of widget.js + /api/feedback Custom feedback submission endpoint (optional).

🐳 Deploying the Central Service

Deploy the biocore_feedback service once on your server using Docker Compose:

# 1. Clone the repository on your server git clone https://github.com/lucacozzuto/biocore_feedback.git cd biocore_feedback # 2. Configure .env with your Slack Incoming Webhook cp .env.example .env nano .env # set SLACK_WEBHOOK_URL="https://hooks.slack.com/services/..." # 3. Start the container docker compose up -d --build

The service listens on port 8080. You can place Nginx or Apache in front with SSL (e.g. https://feedback.crg.es).
